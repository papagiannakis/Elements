
The features in this project is : 
1) Billboard Label component
2) Subtitle System
3) Beautification 
4) Screenshot functionality

Usage instructions : 
1) Ensure you have the Pillow library installed
    **pip install Pillow**

2) Navigation 
   **cd Elements/extensions/Project**

3) run the examples

** Press 'P' for a screenshot

Assumptions & Constraints : 
1) Framework 
   -> Built and tested specifically for the Elements ECSS library
2) Graphics 
   -> Requires an OpenGL 4.1+ compatible enviroment

Files included: 
1) beautification.py 
2) screenshot.py , !!! You cannot screenshot in all examples !!!
3) billboard_label_component.py 
4) subtitle_system.py 
5) beautification+Screenshot.py example
6) examples for subtitles and labels
7) tests 
8) README FILE
